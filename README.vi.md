## Tạo video

### HyperFrames

Viết composition bằng HTML/CSS/JS, render ra video qua headless browser.

| Dự án | Mô tả |
| --- | --- |
| [hyperframes](https://github.com/heygen-com/hyperframes) | Bản thân framework. Viết composition bằng HTML thuần, render video ổn định (deterministic). |
| [auto-compare-video](https://github.com/Cuongyd196/auto-compare-video) | Video so sánh kiến thức (dạng giải thích song song). Tác giả CườngIT. |
| [auto-video-gen](https://github.com/Cuongyd196/auto-video-gen) | Video tin tức tạo từ file hoặc URL. Tác giả CườngIT. |

### Remotion

Dùng React component làm khung hình video.

| Dự án | Mô tả |
| --- | --- |
| [remotion](https://github.com/remotion-dev/remotion) | Framework gốc. Tạo video bằng code React. |
| [remotion-cuongit-template](https://github.com/Cuongyd196/remotion-cuongit-template) | Template Remotion dùng được ngay. Tác giả CườngIT. |
| [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) | Tạo video theo từng shot, xây trên Remotion. |

### HTML / Web

| Dự án | Mô tả |
| --- | --- |
| [html-video](https://github.com/nexu-io/html-video) | Chuyển trang HTML thành video. |

### Workflow & Khác

| Dự án | Mô tả |
| --- | --- |
| [OpenMontage](https://github.com/calesthio/OpenMontage) | Tự động hoá dựng/montage mã nguồn mở. |
| [vox-director](https://github.com/Alisa0808/vox-director) | Điều khiển dựng video bằng giọng nói. |
| [flowkit](https://github.com/crisng95/flowkit) | Bộ công cụ cho workflow Google Flow. |

## Text-to-Speech & Clone giọng nói

Tất cả dự án dưới đây đều **có tiếng Việt**.

| Dự án | Mô tả |
| --- | --- |
| [VieNeu-TTS](https://github.com/pnnbao97/VieNeu-TTS) | TTS ưu tiên tiếng Việt. |
| [OmniVoice](https://github.com/k2-fsa/OmniVoice) | TTS clone giọng chất lượng cao, hỗ trợ 600+ ngôn ngữ. |
| [edge-tts](https://github.com/rany2/edge-tts) | Thư viện Python gọi TTS online của Microsoft Edge. Không cần API key. |
| [OmniVoice-Studio](https://github.com/debpalash/OmniVoice-Studio) | Clone giọng nói và lồng tiếng video chạy local. |
