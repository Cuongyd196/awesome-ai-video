# 📹 Awesome AI Video [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of papers, tutorials, tools, and open-source projects for **video generation with AI**.

Rendering code into video, generating news clips from a URL, cloning a voice, dubbing a whole video — the open-source stack is now good enough to do all of it. This list tracks the projects that actually work.

## Video Generation

### HyperFrames

HTML/CSS/JS compositions rendered to video through a headless browser.

| Project | Description |
| --- | --- |
| [hyperframes](https://github.com/heygen-com/hyperframes) | The framework itself. Write a composition in plain HTML, render deterministic video. |
| [auto-compare-video](https://github.com/Cuongyd196/auto-compare-video) | Knowledge-comparison videos (side-by-side explainer format). By CườngIT. |
| [auto-video-gen](https://github.com/Cuongyd196/auto-video-gen) | News videos generated from a local file or a URL. By CườngIT. |

### Remotion

React components as video frames.

| Project | Description |
| --- | --- |
| [remotion](https://github.com/remotion-dev/remotion) | The framework. Make videos programmatically in React. |
| [remotion-cuongit-template](https://github.com/Cuongyd196/remotion-cuongit-template) | Ready-to-use Remotion starter template. By CườngIT. |
| [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) | Shot-based video creation built on Remotion. |

### HTML / Web-based

| Project | Description |
| --- | --- |
| [html-video](https://github.com/nexu-io/html-video) | Turn HTML pages into video. |

### Workflow & Other

| Project | Description |
| --- | --- |
| [OpenMontage](https://github.com/calesthio/OpenMontage) | Open-source montage / editing automation. |
| [vox-director](https://github.com/Alisa0808/vox-director) | Voice-driven video direction. |
| [flowkit](https://github.com/crisng95/flowkit) | Toolkit for Google Flow workflows. |

## Text-to-Speech & Voice Cloning

All entries below support **Vietnamese**.

| Project | Description |
| --- | --- |
| [VieNeu-TTS](https://github.com/pnnbao97/VieNeu-TTS) | Vietnamese-first TTS. |
| [OmniVoice](https://github.com/k2-fsa/OmniVoice) | High-quality voice cloning TTS for 600+ languages. |
| [edge-tts](https://github.com/rany2/edge-tts) | Python wrapper around Microsoft Edge's online TTS. No API key needed. |
| [OmniVoice-Studio](https://github.com/debpalash/OmniVoice-Studio) | Local voice cloning and video dubbing. |
